```
System BG：QoQ -12.5%（指引中點）→ 絕對金額下降 → 佔比從 57.3% 降至 ~50-57%
Server BG：B300/GB300 首個全季 → 佔比從 21.5% 擴大至 ~22-25%
OP ex-Server：隨 OP 總體 QoQ -7.5%，但 Server 搶走份額 → 佔比回升至 ~22-25%
AIoT BG：穩定 ~2%
```

### 我的猜測

> **三個情境都系統性低估了 Server，高估了 System。**
> 以 Q3 2025 Server 佔比（~51.7% of OP）沿用至 Q4，反推結果是最接近實際的估計。

| BG | 猜測佔比 | 依據 |
|---|---|---|
| System BG | **~50~51%** | PC QoQ -12.5% 加上 Server 搶份額，比 Conservative (55.3%) 更低 |
| Server BG | **~23%** | B300/GB300 Q4 首個全季，出貨量超預期；Q3 比例沿用是最佳錨點 |
| OP ex-Server | **~24%** | OP 總體 QoQ -7.5%，Server 搶走份額後剩餘 |
| AIoT BG | **~2%** | 穩定，無特殊催化劑 |

> 若季報 Server 佔比 > 25%，代表 B300/GB300 出貨超出預期甚至 Q3 比例也低估了。
