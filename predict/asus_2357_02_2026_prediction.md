## 二、預測

### 2026年2月 = 去年2月（456.3億）× 預測 YoY 成長率

| 情境 | YoY | 預測月營收 | 理由 |
|---|---|---|---|
| Conservative | **+45%** | **~661億** | 1月前拉效應部分消退，2月需求略降 |
| Base Case | **+55%** | **~707億** | Server 交貨持續強勁，需求維持高檔 |
| Optimistic | **+65%** | **~753億** | 關稅前拉效應延續，接近1月 +80% 水準 |

### 成長率判斷依據

```
2026/01 實際 YoY = +80%
  ↓ 2月通常較1月回落（復工初期拉貨，1月CNY訂單已消化）
  ↓ 但 Server BG 需求持續，不會大幅衰退
  → 2月 YoY 估計落在 +45% ~ +65%，Base Case +55%
```

### 我的猜測

> **Base Case，偏向上行（+55~60% YoY → ~707~730億）**

| 因素 | 方向 | 說明 |
|---|---|---|
| B300/GB300 伺服器出貨 | ↑ 正面 | 結構性需求，Q1 2026 仍在加速期 |
| 關稅前拉效應 | ↑ 正面 | 美國客戶搶在加徵前備貨，Q1 持續，非一次性 |
| Feb 2025 基期偏低 | ↑ 正面 | 456億，YoY 分母小，成長率容易偏高 |
| CNY 工作天數少 | ↓ 負面 | 2月約 20 天 vs 1月 23 天，出貨量受壓 |
| 1月部分訂單提前認列 | ↓ 負面 | +80% 含有跨月拉貨，2月有消化期 |

```
最終猜測：+55~60% YoY → ~707~730億
  若 > 730億：關稅前拉比預期更強（Optimistic 情境成立）
  若 < 661億：1月 +80% 有一次性因素，需下修 Q1 預測
```
